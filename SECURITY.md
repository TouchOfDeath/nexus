# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v8.6.x  | :white_check_mark: |
| < v8.6  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, buffer overflow, or arbitrary code execution bug in the NEXUS compiler, native runtime emitters (`nexelf`, `nexmacho`, `nexarm64`), or standard library:

1. Please **do not** open a public GitHub issue immediately.
2. Report the vulnerability privately via GitHub Security Advisories or contact the maintainers directly at `amrutanshusahoo.kv@gmail.com`.
3. Include a minimal reproducible test case (`.nex` file), host operating system details, and exact compiler steps to trigger the bug.
4. We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
