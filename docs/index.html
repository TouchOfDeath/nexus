Modern Language Syntax

Readable, concise imperative systems programming with zero runtime overhead.

showcase.nex (NEXUS v8.6) 100% Native Code 
include "stdlib/nstdlib.nex"
include "stdlib/ring_buffer.nex"

# 1. Compile-time constants and operator precedence (* before +)
const MAX_CAP = 65536
const OCT_PERM = 0o755
let calc = 1 + 2 * 3              # Evaluates to 7 (standard precedence)

# 2. Modern range loops and null coalescing
let opt_title = 0
let title = opt_title ?? "NEXUS v8.6"
for i in 0..=10 step 2 {
    # Iterates through 0, 2, 4, 6, 8, 10
}

# 3. Closures & anonymous functions (Lambdas with environment capture)
let factor = 10
let offset = 7
let affine = |x| x * factor + offset
let r_aff = affine(4)             # Evaluates to 47

# 4. Multiple return values and tuple destructuring
fn divmod(a, b) {
    return a / b, a % b
}
let quotient, remainder = divmod(14, 3)

# 5. Standard library data structures (Circular Ring Buffer / Deque)
let rb = nx_rb_new(8)
nx_rb_push_back(rb, 100)
nx_rb_push_front(rb, 50)
let front_val = nx_rb_pop_front(rb) # 50

print "[+] NEXUS v8.6 execution successful!"

Compiler Pipeline & Verification

Pure mathematical determinism verified across operating systems.

Stage 5 Self-Hosting

The compiler compiles itself through 4 consecutive generations. Generation 3 and Generation 4 produce 100% bit-for-bit identical binaries across all 49,152 bytes.

Zero External Toolchains

NEXUS does not invoke GCC, Clang, or NASM. It synthesizes x86-64 machine instructions and ELF/PE headers byte by byte directly in memory.
