Modern Language Syntax

Readable, concise imperative systems programming with zero runtime overhead.

showcase.nex (NEXUS v6.9) 100% Native Code 
include "stdlib/nstdlib.nex"

# 1. Parameterized functions with expression return and default arguments
fn greet(name, times = 1) {
    let i = 0
    while i < times {
        print name
        let i = i + 1
    }
    return times
}

# 2. Closures & anonymous functions (Lambdas with environment capture)
let factor = 10
let offset = 7
let affine = |x| x * factor + offset
let r_aff = affine(4)             # Evaluates to 47

# 3. Higher-order functions accepting closures
fn apply_twice(f, val) {
    return f(f(val))
}
let res = apply_twice(|x| x * 2, 5)  # Evaluates to 20

# 4. Multiple return values and tuple destructuring
fn divmod(a, b) {
    return a / b, a % b
}
let quotient, remainder = divmod(14, 3)

# 5. Lexical local scoping and block shadowing
let x = 10
if x > 5 {
    local x = 999                 # Strictly bounded to this { ... } block
    print x                       # Prints 999
}
print x                           # Automatically unshadowed: prints 10

# 6. Array literals and hardware indexing
let primes = [2, 3, 5, 7, 11, 13]
primes[0] = 42
let first = primes[0]

print "[+] NEXUS v6.9 execution successful!"

Compiler Pipeline & Verification

Pure mathematical determinism verified across operating systems.

Stage 5 Self-Hosting

The compiler compiles itself through 4 consecutive generations. Generation 3 and Generation 4 produce 100% bit-for-bit identical binaries across all 49,152 bytes.

Zero External Toolchains

NEXUS does not invoke GCC, Clang, or NASM. It synthesizes x86-64 machine instructions and ELF/PE headers byte by byte directly in memory.
